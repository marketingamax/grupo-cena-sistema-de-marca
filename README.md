# Rebranding CENA

Apresentação do rebranding da CENA em formato de site, com a proposta de sistema de marca do Grupo CENA.

- `index.html`: o site, em uma página única.

HTML puro, sem etapa de build. Abra `index.html` no navegador.

Documento de trabalho em discussão. Logotipos, cores e textos são propostas e podem mudar. As marcas de terceiros que aparecem no estudo de mercado pertencem aos seus donos e estão ali só para comparação.
